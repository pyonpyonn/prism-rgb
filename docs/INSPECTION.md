# Inspection findings and limits

Prism RGB is an independently written RGB studio. Its initial research examined readable device descriptors and effects from SignalRGB 2.5.80, using REA 6.5.0 alongside manual source and PE-header inspection. SignalRGB does not need to be installed to run Prism.

## What was observed

The inspected SignalRGB application was a native Windows x64 PE executable, not a .NET assembly or Electron package. Its imports included Qt QML/Quick, Qt WebEngine, JavaScript evaluation, rendering, and Windows file/device-I/O entry points. Imported function names suggest investigation boundaries; they do not establish complete runtime behavior.

The application bundle contained 462 JavaScript device plugins, 209 JSON component definitions, five bundled HTML effects, and Qt runtime resources. Loose Qt QML files were mainly framework components; their presence does not mean the application's UI source was recovered.

### Readable device descriptions

Plugin exports describe names, USB vendor/product identifiers, endpoint validation, layout, controls, and initialization/render/shutdown callbacks. These are useful for studying how a lighting host connects effects to hardware.

The included `compatibility-catalog.json` retains only the descriptive fields used by Prism: **Name, Publisher, Kind, VendorId, and ProductId**. Dynamic identifier expressions are left unresolved. The entries are research references, not executable drivers or verified Prism compatibility. Original plugin source, artwork, and effects are not included.

### MSI whole-header protocol

The inspected MSI 185-byte controller plugin exposed report `0x52`, header mode/color offsets, and a no-save tail. The `0x7C95` configuration described two RGB and two ARGB headers. Prism's separate implementation is limited to the exact **B550M PRO-VDH WIFI (MS-7C95), USB 1462:7C95** combination.

The adapter reads an existing 185-byte lighting report before allowing output. For selected headers, it writes static-mode/color fields in a copy and clears the flash-save flag. It preserves unrelated bytes and does not implement the larger per-LED protocol, firmware commands, configuration probes, or other board families.

Version 0.2.0 live tests on the exact target controller verified dim-color mode/color readback on all four headers and restoration of the previous header fields. The firmware changed unused byte 62 internally after processing, so full report identity is not claimed. Actual LED appearance still requires user observation. The descriptor exposes a 725-byte maximum feature buffer and a 185-byte report 0x52; both are validated before output. See [usage](USAGE.md).

### Effects

The bundled Rainbow effect used a 320Ã—200 HTML canvas and animation callbacks. REA's first HTML pass explicitly excluded the inline JavaScript from semantic analysis. Its script body was therefore extracted as inert text, with provenance recorded locally, and analyzed separately: 160 AST nodes, one parsed JavaScript file, and zero parse failures.

The selected MSI script analysis visited 10,119 AST nodes and reported zero parse failures. Static graphs are partial evidence and do not prove that a path executes. Prism's seven native effects were written independently; the original effect source is not bundled.

## Native analysis remains incomplete

Ghidra 12.1.4 and Temurin JDK 21 passed REA's Windows readiness checks. Two attempts to analyze the full 118 MB executable each reached a 240-second provider timeout. Disabling an additional expensive analysis stage did not produce a completed native overview or decompiled-function result.

No claim is made that the compiled core, proprietary service implementation, or complete application architecture has been recovered. Further work should use a persistent native-analysis project, bounded targets, and individually verified findings. General plugin execution, fan/audio/game/LCD services, and broad hardware support remain separate research tasks.

## What is published

This repository contains original Prism source, documentation, a factual reference catalog, a preview generated by Prism, and runtime notices. The release also contains the portable application and source.

Local installation paths, machine inventories, evidence dumps, debug symbols, account files, cookie databases, and private logs are excluded. No SignalRGB licensing checks were patched. The inspected installation was left unchanged.

## Validation scope

Version 0.2.0 passes 15 core and 11 interface checks. Core tests use a fake native MSI transport for duplicate suppression, byte preservation, serialization, failure cleanup, conflicts, and restoration. Automated tests send no physical lighting frames. UI checks cover navigation, scene/profile controls, catalog loading, stopped hidden/static timers, idle screen capture, and the actual close-window path.

Separate live controller checks confirmed header mode/color readback and restoration on the target board. [Performance measurements](PERFORMANCE.md) describe resource results and limits. Broad device support, sleep/resume, physical LED appearance, per-LED geometry, and multi-monitor/protected capture remain unverified.
