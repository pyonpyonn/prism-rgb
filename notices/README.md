The portable release bundles Microsoft's .NET Windows Desktop runtime. Preserve these runtime notices when redistributing the binary:

`compatibility-catalog.json` contains factual reference metadata derived from readable SignalRGB device descriptions: device names, publisher names, kinds, and literal USB identifiers. It contains no plugin bodies, artwork, or driver implementation. Publisher attribution is retained per entry. The catalog is not a hardware-support promise and should not be represented as independently authored device support.
